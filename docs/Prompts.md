# Prompts

Reusable prompts for working with the content framework (`1_CONTENT_CREATION_FRAMEWORK.md`) and the audit protocol (`2_CONTENT_AUDIT_PROTOCOL.md`).

---

## Prompt 1: Create a New Page or Blog Post

```text
Read 1_CONTENT_CREATION_FRAMEWORK.md. Draft the complete content (and metadata/schema if applicable) for [Page/Topic Name] targeting [Target Audience] with the primary page job of [Page Job].

Ensure you follow Define → Explain → Prove → Help, eliminate the Inference Tax, write at Level 3–5 on the Specificity Ladder, and obey Rule 0.1 (use [TODO: INSERT VERIFIED FACT] placeholders instead of inventing fake metrics) and Rule 0.2 (natural human cadence with zero AI clichés).
```

---

## Prompt 2: Audit an Existing Page Without Editing Yet

```text
Read 1_CONTENT_CREATION_FRAMEWORK.md and 2_CONTENT_AUDIT_PROTOCOL.md. Run a complete audit on @[filename] using the Required Audit Output Template in Section 3 of the Audit Protocol. Quote exact weak lines and provide WEAK → STRONGER rewrites.
```

---

## Prompt 3: Audit AND Refactor a File in Place

```text
Read 1_CONTENT_CREATION_FRAMEWORK.md and 2_CONTENT_AUDIT_PROTOCOL.md. First, diagnose @[filename] against the Answerability Test, Specificity Ladder, and Human Readability rules. Then, directly refactor @[filename] to fix all FAIL and WARN items while preserving the layout/components. Insert [TODO: INSERT VERIFIED PROOF] wherever proprietary company metrics or credentials are needed.
```
